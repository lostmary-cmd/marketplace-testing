# Bug Report — Login Validation Error

## ID
BUG-002

## Название
Система принимает пустой пароль при авторизации

## Шаги воспроизведения
1. Открыть страницу логина
2. Ввести email
3. Оставить пароль пустым
4. Нажать Авторизация

## Фактический результат
Система отправляет запрос авторизации

## Ожидаемый результат
Появляется ошибка валидации обязательного поля

## Severity
Major

## Priority
Medium
