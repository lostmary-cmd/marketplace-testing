# Bug Report — Payment Error

## ID
BUG-001

## Название
Ошибка при оплате банковской картой

## Описание
При попытке оформить заказ и оплатить его банковской картой пользователь получает ошибку 500 Internal Server Error.

## Предусловия
- Пользователь авторизован
- Товар добавлен в корзину

## Шаги воспроизведения
1. Открыть корзину
2. Нажать "Оформить заказ"
3. Выбрать оплату банковской картой
4. Нажать кнопку "Оплатить"

## Фактический результат
Появляется ошибка 500 Internal Server Error

## Ожидаемый результат
Платёж успешно обрабатывается и заказ создаётся

## Severity
Critical

## Priority
High
