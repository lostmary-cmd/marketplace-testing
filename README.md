# Marketplace Testing Portfolio

## О проекте
Pet-проект по тестированию маркетплейс-платформы.

В рамках проекта проводилось:
- тестирование пользовательских сценариев
- тестирование REST API
- составление тест-кейсов и чек-листов
- оформление баг-репортов
- анализ HTTP-запросов через DevTools

## Что тестировалось
- Авторизация
- Каталог товаров
- Корзина
- Оформление заказа
- Личный кабинет продавца
- Платёжный модуль

## Инструменты
- Postman
- Chrome DevTools
- GitHub Issues
- REST API
- Notion

## Структура репозитория
- test-cases — тест-кейсы
- checklists — чек-листы
- bug-reports — баг-репорты
- api-testing — коллекции Postman и API testing
