# API Testing

В рамках проекта проводилось тестирование REST API маркетплейс-платформы.

## Что тестировалось
- Авторизация пользователей
- Проверка status codes
- Валидация обязательных полей
- Обработка ошибок
- CRUD-операции

## Инструменты
- Postman
- REST API
- JSON

## Проверяемые статус-коды
- 200 OK
- 400 Bad Request
- 401 Unauthorized
- 404 Not Found
- 500 Internal Server Error
